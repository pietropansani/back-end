📌 O que é JavaScript?
JavaScript é uma linguagem de programação utilizada principalmente para tornar páginas e aplicações web interativas e dinâmicas. Com ela, é possível criar funcionalidades como menus, animações, validações de formulários, alterações de conteúdo e muito mais.

O JavaScript pode ser executado diretamente no navegador e também em servidores por meio de ambientes como o Node.js.

🚀 Principais características
Linguagem de alto nível e relativamente fácil de aprender.

Permite criar páginas web interativas.

Funciona em navegadores como Chrome, Firefox e Edge.

Pode ser utilizado no front-end e no back-end.

Possui um grande ecossistema de bibliotecas e frameworks, como React, Vue e Angular.

Em resumo, JavaScript é uma das principais linguagens utilizadas no desenvolvimento web, permitindo transformar páginas estáticas em aplicações interativas e funcionais.
